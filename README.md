# PT Web Lab

מעבדת לימוד באבטחת יישומי Web מאת **איתי בכור**.

![PT Web Lab](images/slides/slide-01.png)

פיתוח מערכת הרשמה והתחברות ב־Python ו־Flask, פריסה על Kali Linux מאחורי Nginx ו־OPNsense, בדיקות אבטחה מבוקרות ותיעוד התוצאות.

> **מצב המאגר:** חבילת התיעוד מוכנה. קובצי המקור הסופיים מהקאלי טרם צורפו. המאגר בשלב זה אינו חבילת התקנה של האפליקציה.

## מטרת הפרויקט

לתרגל כיצד בקשה עוברת ממחשב הבדיקה, דרך חומת האש ושרת ה־Web, אל קוד האפליקציה ומסד הנתונים. לבדוק בקרות באמצעות תרחישים מותרים ואסורים, לתקן בעיות ולבדוק שוב.

## רכיבי המעבדה

| רכיב | שימוש |
|---|---|
| Python / Flask | הרשמה, התחברות, אזור אישי ויציאה |
| SQLite | משתמשים ו־Sessions |
| Werkzeug / scrypt | גיבוב סיסמאות |
| Gunicorn | שרת היישום |
| Nginx | HTTPS ו־Reverse proxy |
| OPNsense | סינון תעבורה והפניית פורט 443 |
| VMware | מכונות ורשתות וירטואליות |
| Nmap / curl / PowerShell | בדיקות ותיעוד תוצאות |

## בקרות שנבדקו

גישה ל־443 ממקור מורשה וממקור חסום, הגבלת ניסיונות כניסה, טיפול בקלט, מאפייני עוגייה, ביטול Session לאחר יציאה, תפוגת Session, בדיקת Origin ואסימון CSRF ביציאה, גבולות סיסמה, TLS וחשיפת נתיבי קבצים נבחרים.

## היקף ומגבלות

כל הבדיקות המתועדות בוצעו במעבדה אישית. אין כאן בדיקה של יעד החברה שהופיע במטלה המקורית, ואין טענה לכיסוי מלא של OWASP או לאבטחה מוחלטת.

מסמך המדיניות הוא הצעה לארגון לדוגמה בן 50 עובדים. הוא כולל הנחיות רחבות יותר מאלו שיושמו במעבדה, ואינו הצהרת תאימות או הוכחה שכל הבקרות הוטמעו.

הגיבוי הועתק מקאלי למחשב Windows. שחזור שירות מלא מהגיבוי לא תועד. תעודת המעבדה היא תעודה עצמית, ובדיקות curl עם ‎-k אינן מאמתות את אמון התעודה.

## תמונות ופרטיות

הצילומים הם הגרסאות שנבחרו לפרסום במצגת. חיתוכים מסירים ערך עוגיית Session ופרטי ממשק לא נחוצים. כתובות IP פנימיות נשמרו כדי להסביר את הרשת. רקע השער והסיום נוצר באמצעות AI ואינו ראיה טכנית.

מסד המשתמשים, סיסמאות, מפתחות TLS פרטיים, גיבויי האתר וייצוא תצורת Firewall מלא אינם חלק מהמאגר.
